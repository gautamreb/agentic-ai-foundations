# Contributing to Agentic AI Foundations

Thank you for your interest in contributing to this learning repository! This guide will help you get started.

## How to Contribute

### Reporting Issues
- Use the GitHub issue tracker to report bugs or suggest enhancements
- Clearly describe the issue with steps to reproduce (for bugs)
- Include your Python version and OS information

### Suggesting Improvements
We welcome suggestions for:
- New examples or exercises
- Additional documentation
- Better explanations of concepts
- Resource recommendations
- Bug fixes

### Making Changes

1. **Fork the Repository**
   ```bash
   git clone https://github.com/gautamreb/agentic-ai-foundations.git
   cd agentic-ai-foundations
   ```

2. **Create a Branch**
   ```bash
   git checkout -b feature/your-feature-name
   ```

3. **Make Your Changes**
   - Follow the existing code style
   - Add comments to explain complex logic
   - Update documentation if needed
   - Test your code thoroughly

4. **Commit Your Changes**
   ```bash
   git add .
   git commit -m "Description of your changes"
   ```

5. **Push and Create a Pull Request**
   ```bash
   git push origin feature/your-feature-name
   ```
   Then create a pull request on GitHub.

## Code Style Guidelines

### Python Code
- Follow PEP 8 style guide
- Use meaningful variable and function names
- Add docstrings to functions and classes
- Include inline comments for complex logic
- Keep functions focused and concise

### Documentation
- Use clear, beginner-friendly language
- Include code examples where helpful
- Link to external resources when appropriate
- Check for typos and grammatical errors

### Examples and Exercises
- Ensure all code is runnable
- Include comprehensive comments
- Provide clear README files
- Test with the specified dependencies

## Adding New Content

### New Code Examples
1. Create a new directory under `examples/`
2. Include a detailed `README.md`
3. Add well-commented Python code
4. Update main `README.md` to reference it

### New Exercises
1. Create files in appropriate `exercises/weekN/` directory
2. Include clear problem statement
3. Provide detailed solution with explanations
4. Ensure exercises build on previous material

### New Documentation
1. Add to appropriate `docs/` file or create new one
2. Follow existing documentation structure
3. Include references and links
4. Update resource lists if adding new materials

## Quality Standards

### Code Must:
- Run without errors with specified dependencies
- Be properly commented
- Follow Python best practices
- Include error handling where appropriate

### Documentation Must:
- Be accurate and up-to-date
- Use correct formatting (Markdown)
- Be beginner-friendly
- Include examples where helpful

## Getting Help

- Open an issue for questions
- Join discussions in the repository
- Check existing issues and pull requests

## Code of Conduct

- Be respectful and inclusive
- Welcome newcomers and help them learn
- Provide constructive feedback
- Focus on education and learning
